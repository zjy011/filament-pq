# Reproducible experiment figures

These figures are generated by `scripts.analyze_results` from saved evaluation
records. `docs/evidence/report_summary.json` contains their measured values,
and `docs/evidence/artifact_manifest.json` records source paths and checksums.
Missing experiments are explicit; no missing seed or fold is imputed.

The error-crop figures contain derived GONG H-alpha images and MAGFiLO annotation
outlines. Image credit: NSO/AURA/NSF/GONG (CC BY 4.0). Annotation credit:
Ahmadzadeh et al., MAGFiLO v1.0, Harvard Dataverse,
[doi:10.7910/DVN/J6JNVK](https://doi.org/10.7910/DVN/J6JNVK), CC BY-NC 4.0.
Crops, contour overlays and layouts were produced by this project.
See [the dataset paper](https://doi.org/10.1038/s41597-024-03876-y).

These reference-annotation overlays are separate from the independent human
review packages, which contain anonymous candidates without reference masks.
